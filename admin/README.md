# Orchestra — Админка

Веб-интерфейс для администратора: пользователи, проекты, подписки.

## Локальная разработка

1. Установите переменную окружения у бэкенда: `ADMIN_SECRET=ваш-секретный-ключ`
2. В папке `admin`: `npm install && npm run dev`
3. Откройте http://localhost:5173 (или порт из вывода Vite)
4. На странице входа введите тот же ключ, что задали в `ADMIN_SECRET`

Бэкенд должен быть запущен на порту 3000 (прокси в vite настроен на `/api` → `localhost:3000`).

## Docker

Админка поднимается вместе с остальными сервисами:

```bash
docker compose up -d
```

- Админка: http://localhost:8081
- Вход: ключ из переменной `ADMIN_SECRET` (в `.env` или в `docker-compose.yml`)

В продакшене задайте надёжный `ADMIN_SECRET` в окружении контейнера `back`.

## Возможности

- **Пользователи** — список всех пользователей, смена подписки (free / standard)
- **Проекты** — список всех проектов, владелец, пометка «удалён» / восстановление
