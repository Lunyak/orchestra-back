## 📊 Текущая структура

```
app/src/
├── App.tsx              # Провайдеры + layout (40 строк)
├── routes.tsx           # Маршруты + lazy-импорты (48 строк)
├── features/            # Фичи (auth, project, scene, script-ui, team)
├── pages/               # Страницы приложения
├── components/          # UI компоненты
├── shared/              # Типы и утилиты
└── sync/                # API и синхронизация

web/src/
├── main.tsx             # Entry point
├── AppShell.tsx         # Импортирует @app/App
└── components/
    └── AppErrorBoundary.tsx

desktop/src/
└── App.tsx              # Импортирует @app/App + локальная синхронизация
```

## 🎯 Преимущества новой структуры

1. **Чистый код** — App.tsx занимается только провайдерами, routes.tsx — только роутами
2. **Нет дублирования** — вся логика в `/app/`, используется и web, и desktop
3. **Легко найти** — роуты в одном месте, страницы в `pages/`
4. **Легко расширять** — новая страница = файл в `pages/` + строка в `routes.tsx`
5. **Feature-Sliced Design** — изолированные фичи с чистым API

## 🚀 Как добавить новую страницу

1. Создать в `app/src/pages/my-page/MyPage.tsx`
2. Добавить lazy-импорт в `app/src/routes.tsx`:
   ```tsx
   const MyPage = lazy(() =>
     import("./pages/my-page/MyPage").then(m => ({ default: m.MyPage }))
   );
   ```
3. Добавить роут:
   ```tsx
   <Route path="/my-page" element={<MyPage />} />
   ```
