# 3D театр: печатный пакет

Лист, который светооператор уносит с репетиции: план зала и таблица приборов текущей сцены.

## Где в интерфейсе

3D театр → сайдбар **Помещение** → секция **Экспорт** → кнопка **Печатный пакет**.

Кнопка активна, когда открыта сцена. Печать идёт через диалог браузера (`window.print`), файл сам не скачивается.

Рядом остаются отдельные выгрузки только плана: SVG, PNG, PDF и «Скопировать план». В них листа приборов нет.

## Что попадает на печать

Две части одного HTML:

1. **План зала** — тот же чертёж, что и экспорт плана (зал, сетка, кресла, софиты, декор). Заголовок — название сцены, если его нет — название проекта.
2. **Лист приборов** — с новой страницы. Строки отсортированы по каналу, при одинаковом канале — по номеру прибора.

В лист входят только **видимые** софиты (`hidden` не печатается). Имя фермы берётся из видимых моделей сцены.

Если софитов нет, таблица показывает «Софитов на сцене нет». Если браузер блокирует окно, в редакторе сообщение «Браузер заблокировал окно печати».

## Колонки листа

| Колонка | Откуда | Как выглядит |
|---------|--------|----------------|
| Номер | `TheaterSpotlight.id` | `3` или `RGB 4`. Своё имя (не автоподпись «Софит N» / «RGB N») — второй строкой. Выключенный прибор (`enabled === false`) — пометка «выкл» |
| Канал | `channel`, иначе `id`; фейдер — `faderId` | `K1` или `K1 F2`. У RGB только канал |
| Цвет | `color` | Квадрат и название палитры. Стандартный луч обычного софита (`#fbbf24`) — «Открытый». Незнакомый цвет печатается как hex |
| Ферма | `mountModelId`, `mountPointId` | `Имя фермы, точка 4`. Без крепления — «—». Ферма не найдена среди моделей — `Ферма {id}` |
| Наведение | `gridCol` / `gridRow`, иначе `target` | `ячейка 2×3` (столбец × ряд, с 1). Иначе «центр сцены», если цель рядом с `[0, _, 1]`. Иначе `x 1.5 м, z 3 м` |
