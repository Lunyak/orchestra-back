# Telegram Bot для Orchestra

## Описание

Telegram-бот для управления репетициями театральной труппы/оркестра. Интегрирован с основным приложением Orchestra.

## Возможности

- ✅ Создание репетиций через бота
- ✅ Опросы о явке на репетиции
- ✅ Профили пользователей с привязкой к Telegram
- ✅ Регистрация новых пользователей
- ✅ Отображение списка участников репетиции
- ✅ Статусы участия: "Буду", "Не буду", "Буду позже"
- ✅ Хранение данных в PostgreSQL через Prisma

## Настройка

### 1. Переменные окружения

Добавьте в файл `back/.env`:

```env
# Telegram Bot
BOT_TOKEN=your_telegram_bot_token_here
OWNER_TELEGRAM_ID=your_telegram_user_id_here
```

**Как получить BOT_TOKEN:**
1. Напишите @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям
4. Скопируйте полученный токен

**Как узнать OWNER_TELEGRAM_ID:**
1. Напишите боту @userinfobot в Telegram
2. Он вернет ваш ID

### 2. Настройка базы данных

Таблицы уже созданы через миграции в `prisma/migrations/`.

Если нужно настроить проект по умолчанию для бота:

```sql
UPDATE "BotSettings" SET "projectSlug" = 'your-project-slug' WHERE id = 'singleton';
```

### 3. Запуск

```bash
cd back
npm run start:dev
```

Бот запустится автоматически вместе с приложением.

## Использование

### Команды для пользователей:

- `/start` - Начать работу с ботом
- `/register` - Зарегистрировать профиль
- `/profile` (или `/me`) - Показать свой профиль
- `/who` - Показать, кто идет на ближайшую репетицию
- `/menu` - Показать меню команд
- `/help` - Справка по командам

### Команды для организатора (OWNER_TELEGRAM_ID):

- `/setrehearsal` - Создать новую репетицию
- `/setgroup` - Настроить группу для опросов

### Процесс создания репетиции:

1. Организатор отправляет `/setrehearsal` боту в личку
2. Бот просит ввести дату (например: "15.02", "завтра", "пятница")
3. Бот просит ввести время (например: "18:00")
4. Репетиция создается, бот предлагает отправить опрос в группу
5. После отправки опроса участники могут нажать кнопки "Буду" / "Не буду" / "Буду позже"

### Настройка группы:

**Способ 1 (автоматический):**
1. Добавьте бота в группу
2. Откройте нужный топик (если используете топики)
3. Отправьте команду `/setgroup` прямо в топике

**Способ 2 (ручной):**
1. Отправьте боту `/setgroup` в личку
2. Введите ID группы и топика в формате: `-1001234567890/41051`

## Интеграция с Orchestra

### Таблицы БД:

- **UserProfile** - профили пользователей с привязкой к Telegram
- **Rehearsal** - репетиции (созданные через веб или бот)
- **RehearsalParticipant** - участники репетиций со статусами
- **BotSettings** - настройки бота (ID группы, топика, проект по умолчанию)

### API для интеграции:

Бот использует существующие сервисы:
- `RehearsalsService` - для создания и управления репетициями
- `ProfileService` - для работы с профилями
- `PrismaService` - для доступа к БД

## Миграция с старого бота

Если вы переносите данные со старого бота (Dophamin):

1. **Профили пользователей:**
   - Старые профили из `server/src/users` нужно перенести в `UserProfile`
   - Убедитесь, что `telegramId` заполнен для всех пользователей

2. **Репетиции:**
   - Старые репетиции хранились в JSON (`bot/data/rehearsal.json`)
   - Теперь они в таблице `Rehearsal` в PostgreSQL

3. **Персонажи:**
   - Раньше: `user.characters` в TypeORM
   - Теперь: `userProfile.characters` (JSON) в Prisma

## Troubleshooting

### Бот не запускается

- Проверьте, что `BOT_TOKEN` установлен в `.env`
- Проверьте логи приложения

### Бот не отправляет опросы в группу

- Убедитесь, что бот добавлен в группу
- Проверьте, что группа настроена через `/setgroup`
- Для топиков: убедитесь, что бот имеет права на отправку сообщений в топик

### Профиль не найден

- Пользователь должен сначала зарегистрироваться через `/register`
- Проверьте, что `telegramId` правильно сохранен в БД

### Ошибки Prisma/миграции

- Версия Node.js должна быть >= 20 для Prisma 7
- Если возникают проблемы, примените миграции вручную через psql
