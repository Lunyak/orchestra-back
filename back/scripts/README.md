# Скрипты миграции данных

## fix-role-characters.ts

### Описание
Этот скрипт исправляет ошибку в структуре данных, где поле `role` (роль в театре) содержит массив персонажей вместо названия роли.

### Проблема
- **Текущее состояние (неправильно):**
  - `role`: `["Серге Петрович", "Зубрицкий", "Гурий"]`
  - `characters`: `null` или `[]`

- **Ожидаемое состояние (правильно):**
  - `role`: `"Актер"`, `"Режиссер"`, `"Продюсер"` и т.д.
  - `characters`: `["Серге Петрович", "Зубрицкий", "Гурий"]`

### Что делает скрипт
1. Получает всех пользователей из базы данных
2. Для каждого пользователя проверяет, является ли поле `role` JSON-массивом
3. Если да, то:
   - Переносит массив персонажей из `role` в `characters`
   - Очищает поле `role` (устанавливает в `null`)
4. После миграции пользователь может установить правильную роль в театре через бота

### Как запустить

```bash
cd back
npm run migrate:fix-roles
```

### Примечания
- Скрипт безопасен и не удаляет данные - только перемещает их между полями
- После запуска скрипта пользователям нужно будет установить свою роль в театре через бота:
  1. Открыть профиль: `/profile`
  2. Нажать "🔄 Обновить данные"
  3. Нажать "Изменить роль в театре"
  4. Выбрать роль из списка (Актер, Режиссер, Продюсер и т.д.)

### Проверка результатов
После запуска скрипта проверьте профиль в боте:
- **Роль в театре:** должна быть "Не указана" (до тех пор, пока пользователь не установит)
- **Роли/персонажи:** должны отображаться правильно (список персонажей)
